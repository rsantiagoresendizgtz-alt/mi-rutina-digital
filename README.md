 # Mi Rutina Digital

**Curso:** Fundamentos de Programación

Este repositorio contiene las actividades de la primera semana del curso, incluyendo el diseño de un algoritmo para calcular el tiempo dedicado a plataformas digitales.

También incluye el diagrama de flujo, la calculadora desarrollada en Python y el algoritmo de división sintética.
## Semana 2: La Taquilla del Museo

En esta actividad se desarrolló un programa en Python para calcular el precio de entrada al museo según la edad de los visitantes, aplicar los descuentos correspondientes y generar un corte de caja.

La carpeta `semana2/` contiene la tabla de decisión, el diagrama de flujo y el notebook con el programa y sus casos de prueba.
